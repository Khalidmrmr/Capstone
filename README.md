# Smart Closet Mirror

Senior Design (CS 5001 / CS 5002), University of Cincinnati.

## 1. Project

The Smart Closet Mirror turns a secondhand Gen 1 Mirror into a closet assistant. A Kinect 360 measures the user, a home Ubuntu PC shows the user's own clothes and shop items on their body, and the mirror recommends what to wear today and whether a new piece is worth buying. All processing stays in the home.
