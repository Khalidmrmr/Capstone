ID Category Risk Description Likelihood Impact Strategy Mitigation Plan Owner Trigger
R01 Technical WebView 44 Incompatibility: Obsolete Android 6 browser engine rejects ES6/modern CSS, crashing mirror shell UI. High High Reduce Enforce strict Babel ES5 transpile; avoid CSS grid; test all cards in Chromium 44 emulator before mirror deployment (buffered in T18). Clare Logcat syntax error or blank card on device.
R02 Technical Motion-to-Glass Latency > 250 ms: Pose estimation, mesh warping, and H.264 encode create visible mirror lag. Medium High Reduce Use zero-copy shared memory (I7); downscale stream to 480p or fall back to 2D affine warp mode if frame processing > 20 ms (buffered in T09, T10). Arya Watchdog reports pipeline latency > 220 ms.
R03 External Third-Party API Outages / Throttling: Google Calendar or weather APIs throttle requests or suffer outages. Medium Medium Avoid Implement L7 stale-while-revalidate local caching (24h TTL); fall back to default seasonal context bundles (buffered in T12, T15). Jace L7 logs 3 consecutive HTTP 429/5xx responses.
R04 Team Academic Workload Spikes: Midterm exam periods or project deliverables cause sprint handoff bottlenecks. High Medium Reduce Incorporate explicit 15–20% buffer on all tasks; lock Spring Break as zero-task recess; cross-train subsystem pairings. Team Any task slips > 4 calendar days past start date.
R05 Technical Kinect USB Isochronous Packet Drops: Linux USB 2.0 driver drops packets under CPU spikes, stalling pipeline. Low High Reduce Assign real-time SCHED_FIFO priority to L1 daemon; automated 2-second USB re-enumeration fallback (buffered in T01). Rehman L1 emits capture.health = DOWN for > 2 s.
R06 External Kinect Bracket Mechanical Drift: 3D-printed clip bracket flexes or slips, distorting cm ground-truth sizing. Low Medium Avoid Print bracket with stiffening gusset in PETG; run 10-second reference plane calibration check during boot (buffered in T06). Rehman Extracted user height deviates > 10% across runs.
